# `tree` — arena 支撑的通用树容器（ct-pkg 包）

给 JSON、XML 以及其他树形标准共用的**存储与导航层**。它不认识任何一种格式：
格式语义留在各自的包里，本包只提供 arena + 下标的节点存储、`kind` 形状与迭代门面。

## 1. 定位与边界

- **只做存储与门面**：节点存 `{kind, type_sig, payload_index, count}`，孩子下标数组与键值对数组
  全部从 arena 分配；节点内不嵌 `Vec` / `Map`，整树一次 `free_all` 释放。
- **`kind` 按存储形状定义**：标量叶 / 有序孩子 / 键值孩子 + 类型签。**不得出现格式专属名字**
  （如 `json`、`xml`、`null`、`element`），这条是卡面守卫条款。
- **格式层只做两个薄转换**：`enum ↔ Node` 记录。缺失语义（JSON 的 null、XML 的空元素等）
  留在格式包的转换层，不进入本包。
- **不定义节点枚举**：`JsonNode`、`XmlNode` 各自在自己包里；共享语义模型若将来需要，
  在本包之上加层，不回改核心。
- **不新建格式解析器**：解析由格式包实现，本包只提供「暂存 `Vec` → 冻结进 arena」的写入路径。

## 2. 依赖

`ct.pkg` 的 `requires` 反映已用到的语言能力；`as<T>` / `to<T>` 依赖语言侧「泛型入口三件套」
（impl 内泛型方法、跨单元实例发射、限定调用携带类型实参），三件套落地前该 API 不交付。
