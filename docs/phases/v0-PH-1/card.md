## 范围

**做**：

- 节点记录 `{kind, type_sig, payload_index, count}`；孩子下标数组与键值对数组从 arena 分配。
- `kind` 三形状：标量叶 / 有序孩子 / 键值孩子；**不得出现格式专属名字**（守卫条款）。
- 写入路径：「暂存 `Vec` → 冻结进 arena」；分块增长只作流式备选。
- 迭代门面：`length()` / `at(i)` / 键值入口，命名按未来语言迭代协议会消费的形态。
- 导航宽容、写严格；取值两档：`as<T>`（宽松缺省）与 `to<T>`（严格，返回 `Option`）。
- 文档按格式写成契约条款，每条配负例；明示「节点绑定 arena、子树不跨文档移动」。

**不做**：

- 不定义节点枚举（`JsonNode` / `XmlNode` 在格式包）；不建公开的具体函数面板。
- 不做格式解析器与 schema 生成器本体（生成器在格式包侧，本包只提供它消费的 API）。
- 不做 `foreach` 语法支持、绑定点裸写糖（各自另立 LANG 卡）。

### S1 验收矩阵

| 夹具 | 覆盖 | 判据 |
| --- | --- | --- |
| `s1_shapes` | 标量叶 / 有序孩子 / 键值孩子三种 `kind` 的写入与读回 | `kind`、`type_sig`、`count` 与写入一致；子下标可解析 |
| `s1_freeze` | 「暂存 `Vec` → 冻结进 arena」 | 冻结后修改或释放暂存容器，不影响 arena 内容 |
| `s1_bounds` | 空树、单节点、深链、越界 `at`、未知 `kind` | 越界与未知返回空节点或明确错误，不崩溃、不读越界 |
| `s1_free` | 整树 `free_all` | ASan 零泄漏；释放后节点不可再用（文档写明） |
| `s1_type_sig` | `int` / `double` / `bool` / `Str` 视图的类型签 | 类型签不一致时读路径拒绝，不静默转换 |
